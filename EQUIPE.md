# Équipe FocusMate

## Présentation de l'équipe

Nous sommes une équipe de trois étudiants travaillant sur le développement de FocusMate, une application web destinée à faciliter l'organisation et le suivi du travail étudiant.

## Organisation

Chaque membre dispose d'une branche Git dédiée et intervient sur les fichiers qui lui sont attribués.

Les modifications sont proposées par Pull Request, relues par un autre membre, puis fusionnées dans la branche principale `master`.
